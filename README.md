# Doc Review

**在文档里批注，让 Codex 在当前聊天中修改，再带着修订记录导出 Word。**

Doc Review 为 Codex 提供一个本地文档审阅页。你可以像审阅 Word 一样选中句子、写下修改要求，也可以直接调整文字、图片和表格。Codex 的修改显示在正文里，回复显示在批注弹窗中，接受或拒绝修订由你决定。

## 安装到 Codex

在 Codex 聊天中发送：

```text
$skill-installer 安装 https://github.com/QING1105/codex-docreview/tree/main/skills/doc-review
```

也可以使用 Skills CLI：

```bash
npx skills add QING1105/codex-docreview --skill doc-review -a codex -g -y
```

## 使用

安装完成后，在 Codex 的下一轮对话中输入：

```text
$doc-review 打开文档批注页
```

技能自动准备运行环境并打开批注页。把 `.docx`、`.md` 或 `.txt` 拖入页面，选中文字即可写批注。也可以直接提供文件路径：

```text
$doc-review 审阅 C:\Documents\draft.docx
```

文档修改、批注回复和操作批准都在发起审阅的那条聊天中完成，使用该聊天的模型。

## 更新

使用 Skills CLI 安装的用户可运行：

```bash
npx skills update doc-review -g -y
```

也可以在 Codex 中说“更新 doc-review 技能”。技能更新后会在首次调用时检查运行环境；文档和批注保存在独立的数据目录中。

## 从批注到修改稿

1. **选中原文。** 在网页里选中要修改的句子，点击批注按钮。
2. **说明要求并发送。** 例如：“这句话太长，请拆成两句，保留原意和引用。”
3. **查看结果。** 批注自动送到启动审阅的那条 Codex 聊天；修改显示在正文里，回复显示在对应批注弹窗中。你可以在弹窗里继续追问。
4. **决定是否采用。** 在同一条聊天中说“接受全部修订”，或指明某段修改需要保留、撤回。
5. **导出 Word。** 点击网页上的“导出 Word”，或在聊天里说“导出修订版 Word”。

审阅、回复和操作批准都留在启动插件的那条聊天中。每个运行实例同时审阅一份文档；结束时在原聊天说“结束审阅”，即可交给另一条聊天使用。

## 可以做什么

| 功能 | 使用方式 |
| --- | --- |
| 句子批注 | 选中文字后添加批注；点击正文高亮或顶部“批注”查看回复 |
| 修订显示 | 新增内容显示为浅绿底下划线，删除内容显示为浅红底删除线；导入 Word 已有的文字修订也会显示 |
| 直接编辑 | 在“编辑”或“建议”模式下，点击正文修改文字 |
| 文字格式 | 调整字体、字号、加粗、斜体、下划线、高亮和文字颜色 |
| 待办与 checklist | 新建待办，或把当前段落转换为 checklist，勾选记录完成状态 |
| 图片 | 添加或删除图片，导入 Word 中的图片继续显示 |
| 表格 | 添加或删除表格，直接编辑单元格内容 |
| Word 导出 | 导出带修订和批注的版本；接受修订后可再导出确认后的正文 |

正文占据主要阅读区域，批注以弹窗展开。`Ctrl+B`、`Ctrl+I`、`Ctrl+U` 分别切换加粗、斜体和下划线；`Esc` 关闭批注弹窗。

### 编辑、建议与查看

- **编辑：** 直接修改正文。段落中已有待处理修订时，新的改动继续保留修订，便于一起审核。
- **建议：** 将你的文字改动记为修订。
- **查看：** 阅读文档、添加批注。

“显示修订”开关控制正文的显示方式。要调整文字或格式，先选择“编辑”或“建议”模式。脚注、域等复杂 Word 结构所在的受保护段落可以通过批注讨论修改。

## 检查环境

在聊天中让技能“检查运行环境”。pip 安装者也可运行 `doc-review doctor`。技能自动准备依赖，并检查文件完整性、文档目录、网页端口及文档工具。

| 遇到的情况 | 处理方法 |
| --- | --- |
| 首次使用需要准备运行环境 | 技能自动通过 pip 安装所需依赖，完成后继续任务 |
| 提示找不到 `codex` 命令 | 继续通过已安装的 `$doc-review` 技能使用；将 Codex CLI 加入 PATH 后重新安装，可补充 MCP 工具注册 |
| Codex 中尚未出现技能 | 重新加载 Codex，再输入 `$doc-review` |
| 网页端口被其他程序占用 | 在原聊天中让技能检查端口占用并调整配置 |
| 批注发送后尚未收到回复 | 在发起审阅的 Codex 聊天里让 Codex 运行 `doctor.cmd`，检查当前桌面的自动投递接口和连接状态 |
| 文字或格式按钮呈灰色 | 将右上角模式切换为“编辑”或“建议”，再选中要操作的文字 |
